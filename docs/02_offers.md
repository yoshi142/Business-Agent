# 02. 商品・価格表（第1.0版）

価格はすべて税抜。消費税の扱いは 05_legal_tax.md を参照。

## 1. 業務自動化診断

| 項目 | 内容 |
|------|------|
| 価格 | 3万円（開業後3か月は無料。紹介経由は常時無料） |
| 所要時間 | ヒアリング60分 ＋ レポート作成（当日〜翌営業日） |
| 納品物 | 診断レポート（PDF）。自動化候補3〜5件、各候補の削減時間・年間効果・構築費・回収期間 |
| 作り方 | `python -m bizagent diagnose --interactive` でたたき台を作り、ヒアリング内容で数字を補正する |
| ねらい | 顧客が「どれをいくらで頼めば、何か月で元が取れるか」を判断できる状態にする |

診断費は、同月内に構築を発注した場合、構築費から差し引く。

## 2. 小さな自動化の構築

| 規模 | 価格 | 構築工数 | 例 |
|------|------|---------|----|
| S | 15万円 | 8〜12時間 | SNS 投稿案の一括生成、議事録自動化、日報の集計要約 |
| M | 25万円 | 12〜20時間 | 問い合わせの仕分けと返信下書き、請求書の読み取りと転記、見積下書き |
| L | 40〜50万円 | 20〜32時間 | 社内 FAQ 窓口、シフト案の自動生成、在庫発注の推奨 |

含むもの：要件の確認1回、構築、動作確認、操作説明（60分）、納品後2週間の不具合修正。
含まないもの：既存システムの改修、個別のアカウント契約代行、2週間を過ぎた後の仕様変更。

価格の根拠は「顧客の年間削減効果の20〜40%」に置く。
たとえば年間60万円の効果が見込める施策なら、15〜25万円。回収期間が3〜6か月に収まる。

## 3. 月額保守・改善

| プラン | 価格 | 内容 |
|--------|------|------|
| 基本 | 3万円／月 | 動作監視、障害対応、月1回の軽微な改善（1時間まで）、API 利用料の実費精算 |
| 拡張 | 5万円／月 | 基本 ＋ 月1回の改善打ち合わせ（30分）＋ 改善3時間まで |

最低契約期間は3か月。以降は1か月前通知で解約できる。
API 利用料は顧客側でアカウントを作ってもらい、顧客が直接支払う形を基本にする（立て替えを避ける）。

## 4. 価格の守り方

- 値引きの代わりに“範囲を削る”。価格を下げる場合は納品物を減らす。
- 「とりあえず安く試したい」には診断（3万円）を案内する。
- 相見積で負けた場合は、理由を聞いて 03_sales_playbook.md の記録に残す。

## 5. 見積書・契約書の骨子

見積書に必ず書く項目：

1. 対象業務と自動化の範囲（診断レポートの候補番号を引用）
2. 納品物（動くもの、設定手順書、操作説明）
3. 顧客側の準備（アカウント、サンプルデータ、担当者）
4. 納期（着手日から営業日で）
5. 支払条件（着手時50%、納品時50%。初回取引は着手時100%も可）
6. 含まないもの
7. 不具合対応の期間（納品後2週間）
8. AI 出力の最終確認は顧客側で行うこと

業務委託契約書の雛形は docs/templates/contract_outline.md。
正式な契約書は、最初の受注時に一度だけ専門家に確認を依頼する（費用は3〜5万円程度を見込み、予備費から出す）。
