# 01. 事業計画（第1.0版）

## 10万円の使い道

| 項目 | 金額（目安） | 備考 |
|------|------------|------|
| 独自ドメイン（1年） | 1,500円 | 信頼性のためメールもドメインで運用する |
| メール・ドキュメント（Google Workspace 1人分、6か月） | 約6,000円 | 既存の無料アカウントで代替可 |
| Claude API 利用料（初期3か月） | 10,000円 | 診断・デモ・納品物の実行費。顧客分は実費請求に切り替える |
| 名刺・簡易ロゴ | 5,000円 | 対面営業用 |
| 開業届・青色申告の準備（会計ソフト 6か月） | 約8,000円 | 05_legal_tax.md 参照 |
| 商工会議所・異業種交流会の参加費 | 10,000円 | 最初の顧客はここから出ることが多い |
| 予備（交通費・サンプル作成の API 費など） | 59,500円 | 使い切らない。現金は残す |
| 合計 | 100,000円 | |

広告費は入れない。初期は“紹介と直接営業”で受注する。広告は売上が立ち、受注率が分かってから検討する。

## 商品の三段階

| 段階 | 商品名 | 価格（税抜） | 内容 | 目的 |
|------|--------|-------------|------|------|
| 1 | 業務自動化診断 | 無料 → 3万円 | 本リポジトリの診断ツール＋60分ヒアリング。レポートを納品 | 入口。課題と金額効果を見える化し、構築につなげる |
| 2 | 小さな自動化の構築 | 15〜50万円 | 診断で選んだ1件を2〜4週間で構築。人が確認する設計 | 主力売上 |
| 3 | 月額保守・改善 | 3〜5万円／月 | 動作監視、月1回の改善、API 費の実費 | 積み上がる売上。解約率を下げる |

詳細は 02_offers.md。

## 90日計画

### 第1〜2週：土台

- 開業届と青色申告承認申請書を提出する（05_legal_tax.md）。
- ドメイン取得、メール設定、サービス案内ページ（site/index.html）を公開する。
- 本リポジトリの診断ツールを自分で10回使い、レシピ（bizagent/data/recipes.json）の文言を自分の言葉に直す。
- 自分の知人・取引先・家族経営の店を対象に、無料診断の“練習台”を3社確保する。

### 第3〜4週：無料診断 10社

- 商工会議所、業界団体、近隣の店舗、知人経由で10社に無料診断を実施する。
- 各社に診断レポート（Markdown → PDF）を渡し、「最初の一歩」として挙げた1件の構築見積を添える。
- 10社中2社の構築受注を目標にする（受注率20%）。取れなければ 03_sales_playbook.md の「断られた理由の記録」を見直す。

### 第5〜8週：初回構築 2件

- 1件目は価格を下げてでも“実績と推薦文”を取る（ただし無料にはしない。最低10万円）。
- 構築したものは必ず汎用化し、2件目以降の原価を下げる。
- 納品時に月額保守を提案する。構築費の15〜20%／月を目安にする。

### 第9〜12週：型を作る

- 診断を有料（3万円）に切り替える。無料は紹介経由のみに限定する。
- 受注した自動化の種類を集計し、需要が多い上位2つを“定額パッケージ”として案内ページに載せる。
- 月次で台帳（ledger）を更新し、ダッシュボードで売上ペースを確認する。

## 18か月の目安

| 月 | 累計売上の目安 | 状態 |
|----|--------------|------|
| 3 | 50万円 | 構築2件、保守1社 |
| 6 | 200万円 | 構築6件、保守4社。紹介が出始める |
| 9 | 400万円 | 月商50万円前後。診断は有料のみ |
| 12 | 600万円 | 保守8社で固定収入30万円／月 |
| 18 | 1,000万円 | 構築20件、保守10社 |

月ごとの到達判定は `python -m bizagent ledger status` の「到達予測」で行う。
2か月続けてペースが表より20%以上遅れたら、単価（上げる）か営業量（増やす）のどちらかを変える。両方を同時には変えない。

## 製品化（受託の次）

受託が10件を超えたら、最も多かった自動化1つを“月額5,000〜15,000円の小さな製品”にする。
対象は、受託時に作ったコードを設定画面付きにしただけのもの。新機能は作らない。
狙いは、営業しなくても積み上がる売上を作ることで、受託の繁閑を均す点にある。

## やらないこと

- 大企業向けの提案。決裁が遅く、1人では対応できない。
- 「何でもやります」の受託。診断で決めた1件だけを納品し、追加は別見積にする。
- 値引き競争。価格ではなく“回収期間の短さ”で説明する。
- 元手の残りを広告に投じること。受注率が分かるまでは行わない。
