# 06. 週次レビュー（毎週同じ曜日に15分）

台帳を更新してから、以下を埋める。前週と比べて、数字が動いていない行が“今週の問題”である。

## 記入欄

| 項目 | 今週 | 先週 | 目標 |
|------|------|------|------|
| 新規接触数 | | | 20 |
| 診断実施数 | | | 2 |
| 見積提示数 | | | 1 |
| 受注数 | | | 0.5 |
| 売上（入金ベース） | | | |
| 累計売上 | | | 1,000万円 |
| 到達予測（ledger status の値） | | | 18か月以内 |
| 保守契約社数 | | | |

## 3つの問い

1. 今週、断られた理由で最も多かったものは何か。対策を1つだけ決める。
2. 今週、作ったもので次の顧客に流用できるものは何か。保存したか。
3. 来週の20件の接触先は決まっているか。決まっていなければ、今ここで10件書く。

## コマンド

```
python -m bizagent ledger add --kind income --category 構築 --amount 250000 --memo "B社 見積下書き"
python -m bizagent ledger add --kind expense --category API --amount 1200 --memo "10月分"
python -m bizagent ledger status
python -m bizagent ledger dashboard   # ledger/dashboard.html を生成
```

## 判断の規則

- 2か月続けて到達予測が「24か月超」なら、単価か営業量のどちらか1つを変える。
- 保守の解約が2社続いたら、解約理由を聞き、納品手順（04_delivery.md）の効果測定を見直す。
- 現金残高が5万円を切ったら、新規の支出をすべて止め、入金待ちの請求を確認する。
