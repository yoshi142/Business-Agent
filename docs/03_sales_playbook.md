# 03. 営業の手引き（第1.0版）

売上が立たない原因のほとんどは「提案の質」ではなく「接触数の不足」である。
この手引きは、接触数を確保し、断られた理由を記録して次に活かすためのものである。

## 対象顧客

| 優先 | 業種 | 典型的な課題 | 最初の提案 |
|------|------|------------|-----------|
| 1 | 建設・リフォーム・設備 | 見積作成、請求書入力、日報 | 見積下書き、請求書読み取り |
| 1 | 士業（税理士・社労士・行政書士） | 問い合わせ対応、契約書確認、議事録 | 問い合わせ仕分け、FAQ 窓口 |
| 2 | 飲食・美容・整骨院 | 口コミ返信、SNS、シフト | 口コミ返信、SNS 投稿案 |
| 2 | 小売・EC | 在庫、顧客フォロー、問い合わせ | 在庫アラート、顧客フォロー |
| 3 | 介護・医療事務 | 日報、シフト、採用 | 日報集計、採用一次対応 |

共通の条件：従業員3〜30名、経営者が自分で決裁できる、既にメール・スプレッドシート・LINE のいずれかを業務で使っている。

## 接触経路（初期はこの順）

1. 知人・元取引先・家族経営の店：最初の3件はここから。「練習台になってほしい」と正直に言う。
2. 商工会議所・業界団体・異業種交流会：月2回参加。名刺交換の翌日に診断の案内を送る。
3. 既存顧客からの紹介：納品時に「同じ悩みを持つ知り合いを1人紹介してほしい」と必ず言う。
4. 地域の店舗への訪問：口コミ対応や SNS で困っている店は外から分かる。
5. SNS・ブログでの事例公開：受注3件を超えてから。事例は顧客の許可を得て匿名化する。

広告は、上記で受注率が分かってから検討する。

## 1週間の行動量（目安）

| 行動 | 回数 |
|------|------|
| 新規の接触（メール・DM・訪問・紹介依頼） | 20件 |
| 無料／有料診断の実施 | 2〜3件 |
| 構築の見積提示 | 1〜2件 |

接触20件 → 診断2件 → 見積1件 → 受注0.3〜0.5件が初期の目安。これを週次レビュー（06_weekly_review.md）で追う。

## 話の組み立て（60分ヒアリング）

1. 0〜10分：相手の業務の流れを聞く。「朝来て最初にやる作業は何ですか」から始める。
2. 10〜30分：時間がかかる作業を3つ挙げてもらい、週に何時間かを本人に見積もってもらう。
3. 30〜45分：診断ツールの結果を見せ、候補ごとに「人が確認する箇所」と「回収期間」を説明する。
4. 45〜55分：最初の1件を一緒に選ぶ。選ばせるのであって、売り込まない。
5. 55〜60分：次の予定を決める（見積提示日、または着手日）。

言ってはいけないこと：「AI が全部やります」「必ず削減できます」。
言うこと：「最終確認は御社で行う設計にします」「数字は目安で、導入後に実測します」。

## 断られたときの記録

断られた理由を `docs/templates/lost_reasons.csv` に1行ずつ記録する。
列：日付、業種、規模、提案内容、価格、理由（予算／時期／信用／必要性／他社）、学んだこと。

月末に集計し、最多の理由への対策を1つだけ決める。たとえば：

- 「信用」が最多 → 事例と推薦文を案内ページに追加する。
- 「必要性」が最多 → 診断の数字の見せ方を変える（削減時間ではなく「月末の残業がなくなる」など）。
- 「価格」が最多 → 単価は下げず、S プランの範囲を作る。

## 文面の雛形

### 紹介依頼（知人向け）

> ○○さん、ご無沙汰しています。△△です。
> 中小企業向けに、問い合わせ返信や見積・請求書作成などの繰り返し作業を AI で自動化する仕事を始めました。
> 今は実績作りの期間で、業務の診断を無料で行っています（60分の聞き取りと、削減できる時間と費用の目安をまとめた資料のお渡し）。
> もし身近に「事務作業で毎日1〜2時間取られている」経営者の方がいれば、ご紹介いただけないでしょうか。
> 私自身の会社の紹介文はこちらです：（案内ページの URL）

### 初回接触（交流会の翌日）

> 昨日は名刺交換をありがとうございました。△△の□□です。
> お話の中で「請求書の処理が月末に集中する」と伺いました。
> 同じ規模の会社では、請求書の読み取りと会計ソフトへの転記を自動化し、月末作業を半日程度に収めた例があります（最終確認は担当者が行う形です）。
> もしよければ、60分の無料診断で御社の場合の削減時間と費用の目安をお出しします。来週、ご都合のよい日はありますか。

### 見積提示後の追いかけ（1週間後）

> 先日お送りした見積について、ご不明点や懸念があれば伺いたくご連絡しました。
> 「まだ早い」という判断であれば、その理由を教えていただけると今後の参考になります。
> もし進められる場合、着手は最短で○月○日からとなります。

### 納品時の紹介依頼

> 本日で納品完了です。2週間は不具合対応を無償で行います。
> もし同じような作業で困っている経営者の方がお知り合いにいれば、1名ご紹介いただけないでしょうか。診断は無料で行います。

## よくある反論と答え

| 反論 | 答え |
|------|------|
| AI は間違える | 間違える前提で、人が確認する箇所を設計に入れている。確認は1件数秒で済む形にする |
| 自分で ChatGPT を使えばいい | その通り。ただし毎回手で貼り付ける作業が残る。それを無くすのがこの仕事 |
| 高い | 回収期間で判断してほしい。年間○○万円の効果に対して○か月で回収できる |
| 今は忙しい | 忙しいから作業を減らす。着手は御社の作業がほぼ不要で、サンプルデータの提供だけで済む |
| 情報漏えいが心配 | 扱うデータの範囲と保存先を書面で決める。API は学習に使われない契約条件を確認して使う |

最後の行の「学習に使われない」という点は、使う API 提供元の利用規約を契約前に確認し、根拠を顧客に示せるようにしておく。
