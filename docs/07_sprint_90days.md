# 07. 90日スプリント（第1関門）

## 条件

| 項目 | 値 |
|------|----|
| 期間 | 2026-10-22 〜 2027-01-20（90日） |
| 判定 | 期間内の売上（入金ベース）が3万円以上なら合格 |
| AI 利用料の上限 | 3万円（`python -m bizagent ledger sprint` で消化状況を表示） |
| 判定コマンド | `python -m bizagent ledger sprint` |

AI 利用料のうち、このリポジトリのツールが呼ぶ API の費用は ledger/api_usage.csv に自動で概算記録される。
Claude Code など、ツール外で使った分は台帳に `--kind expense --category AI利用料` で手入力する。判定には両者の大きい方を使う。

## 方針の変更点

もとの計画は「3万円の診断」を入口にしていたが、初対面の相手に3万円を払ってもらうには信頼の積み上げが要り、90日では間に合わない可能性が高い。
そこで、“1万円・当日納品・成果物が目に見える”入口商品を3種用意し、3件で3万円に到達する設計に変える。
診断（無料）は入口商品への導線として残す。

## 入口商品（いずれも1万円・税込、当日〜翌営業日納品）

| 商品 | 納品物 | 向いている相手 | 作り方 | API 費の目安 |
|------|--------|--------------|--------|-------------|
| A. SNS 投稿案 1か月分 | 30本の投稿文・ハッシュタグ・写真の案（CSV と文書） | カフェ、美容室、整骨院、小売店 | `bizagent mini sns --json 店舗情報.json` | 約30円 |
| B. 口コミ返信案 | 全口コミへの返信文、要確認フラグ、傾向と改善候補 | Google マップの口コミが10件以上ある店 | `bizagent mini reviews --csv 口コミ.csv --name 店名 --business 業態` | 約10〜50円 |
| C. 問い合わせ返信テンプレート10種 | 件名・本文・差し込み箇所・返信後の作業 | 予約や見積の問い合わせが多い事業者 | `bizagent mini inquiry --json 事業者情報.json` | 約20円 |

作業時間は、情報の聞き取り15分、生成5分、目視での修正30分、納品メール10分で、1件あたり約1時間。
1万円は「手直し済みの成果物を当日に受け取れる」ことへの対価であり、生成そのものの対価ではない。
必ず自分で全文を読み、店が提供していない内容や誇張を直してから納品する。

## 90日の進め方

### 第1〜7日：準備と最初の声かけ

- 開業届・青色申告の提出（docs/05_legal_tax.md）。売上3万円でも帳簿は必要。
- 自分の知っている店・事業者を20件書き出す（行ったことのある店で十分）。
- そのうち3件に、商品 A か B を“無料のサンプル”として作って渡す。実物を見せるのが一番早い。
- examples/ の入力例で3商品を1回ずつ実行し、納品の流れを体験しておく（API 費は合計100円以下）。

### 第8〜30日：有料1件目

- サンプルを渡した3件に「1万円で1か月分（または全口コミ分）作ります」と提案する。
- 並行して、接触を週20件行う（docs/03_sales_playbook.md）。文面は下記。
- 目標：30日目までに有料1件（1万円）。

### 第31〜60日：2件目・3件目

- 1件目の納品物を、顧客の許可を得て事例にする（店名は伏せてもよい）。
- 1件目の顧客に「翌月分も1万円で」と継続を提案する。SNS 投稿案は毎月売れる。
- 目標：60日目までに累計3万円。

### 第61〜90日：予備期間と次の関門の準備

- 届いていなければ、断られた理由（docs/templates/lost_reasons.csv）を集計し、商品か文面のどちらかを1つ変える。
- 届いていれば、入口商品の顧客に無料診断を行い、構築（15万円〜）への導線を作る。

## 文面（入口商品用）

### 知っている店への声かけ（LINE・対面）

> こんにちは、△△です。いま、小さなお店向けに Instagram の投稿文を1か月分まとめて作る仕事を始めました。
> ○○さんのお店の分を試しに作ってみたので、よければ見てください（添付）。
> 気に入っていただけたら、1か月分30本で1万円でお作りしています。手直しは何度でも対応します。

### 口コミが多い店への声かけ

> はじめまして。△△と申します。Google マップで○○さんのお店の口コミを拝見し、返信がまだのものが多いようでしたので、
> 試しに3件分の返信案を作ってみました（添付）。
> 口コミへの返信は、新規のお客様が見る場所なので、丁寧に返しておくと来店につながります。
> 全件分の返信案と、口コミから見えた改善点のまとめを1万円でお作りしています。

## 週ごとの確認

毎週、次の2行を記録する（docs/06_weekly_review.md に追記）。

```
python -m bizagent ledger sprint
python -m bizagent ledger add --kind income --category 入口商品 --amount 10000 --memo "○○店 SNS 11月分"
```

## 判定の扱い

売上が3万円に届かなかった場合、原因は次のいずれかであることが多い。

1. 接触数が週20件に届いていない（最も多い）。
2. サンプルを渡していない（口頭説明だけでは買われない）。
3. 商品を安くしすぎた／高くしすぎた（1万円は目安。5,000円のお試しも可）。

90日の時点で、台帳の記録をもとにどれに該当するかを判断し、次の90日の方針を決める。
