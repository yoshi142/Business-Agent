# 業務自動化 診断レポート：山田工務店

作成日：2026-10-22　／　エンジン：簡易診断

## 要約

山田工務店（建設・リフォーム、8名）の記述から、5件の自動化候補を抽出した。合計で週あたり約21.0時間、年間で約2,625,000円相当の人件費削減が見込める。いずれも最終確認は人が行う前提で設計し、業務の品質を落とさないことを優先する。

年間削減効果の合計（目安）：2,625,000円

### 1. 請求書・領収書の読み取りと会計ソフトへの転記

- 現状の課題：紙や PDF の請求書を手入力しており、月末に作業が集中する
- 自動化の内容：PDF や写真から金額・取引先・日付を読み取り、会計ソフトの取り込み形式（CSV）に変換する。読み取り結果は一覧で人が確認する
- 使うツール：Claude API（画像・PDF読み取り）、会計ソフトのCSV取込、Google ドライブ
- 構築工数の目安：16時間
- 根拠：建設・リフォームの8名規模で頻出する作業。記述内容に該当する作業が含まれている。

### 2. 紙・PDF・メールからスプレッドシートへの転記

- 現状の課題：注文書や申込書の内容を手でシステムに打ち込んでいる
- 自動化の内容：書類を AI で読み取り、決まった形式で表に追記する。読み取り精度が低い項目は人が確認する欄を設ける
- 使うツール：Claude API（画像・PDF読み取り）、スプレッドシート、Google ドライブ
- 構築工数の目安：12時間
- 根拠：建設・リフォームの8名規模で頻出する作業。記述内容に該当する作業が含まれている。

### 3. 見積書・提案書の自動下書き

- 現状の課題：過去の見積を探して手で書き換えており、作成に時間がかかりミスも出る
- 自動化の内容：ヒアリング内容と過去の見積データから、見積書と提案書の下書きを自動生成する。単価表はスプレッドシートで管理する
- 使うツール：スプレッドシート、Claude API、Google ドキュメント
- 構築工数の目安：16時間
- 根拠：建設・リフォームの8名規模で頻出する作業。記述内容に該当する作業が含まれている。

### 4. 問い合わせメール・フォームの自動仕分けと下書き返信

- 現状の課題：問い合わせの確認・振り分け・定型返信に毎日時間を取られている
- 自動化の内容：受信メールを AI が分類（見積依頼／予約／クレーム／その他）し、担当者へ振り分け、返信の下書きまで作成する。送信は人が確認してから行う
- 使うツール：Gmail / Outlook、Claude API、スプレッドシート
- 構築工数の目安：12時間
- 根拠：建設・リフォームの8名規模で頻出する作業。記述内容に該当する作業が含まれている。

### 5. 日報・週報の自動集計と要約

- 現状の課題：スタッフの日報を読んで集計・要約するのに管理者の時間が取られている
- 自動化の内容：日報（チャット・フォーム・スプレッドシート）を毎朝自動で集計し、要点と要注意事項を要約して管理者に送る
- 使うツール：Slack / LINE WORKS / Chatwork、スプレッドシート、Claude API
- 構築工数の目安：10時間
- 根拠：建設・リフォームの8名規模で頻出する作業。記述内容に該当する作業が含まれている。

## 最初の一歩

「請求書・領収書の読み取りと会計ソフトへの転記」から着手する。難易度2で構築16時間程度、投資回収は約6.1か月と短く、効果を早く実感できるため。

## 前提と注意点

- 削減時間と金額は、同規模の企業での一般的な目安であり、実測値ではない。
- 導入前に現状の作業時間を1〜2週間計測し、効果を確認してから次の施策に進む。
- 個人情報・機密情報を扱う場合は、取り扱い範囲と保存先を事前に合意する。
- 規則ベースの簡易診断のため、ヒアリングで内容を補正する必要がある。
